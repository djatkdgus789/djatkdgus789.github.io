# djatkdgus789.github.io

Personal academic homepage of Sanghyeon Eom (엄상현), served by GitHub Pages.
The layout is a static HTML/CSS take on the [al-folio](https://github.com/alshedivat/al-folio) theme.

- `index.html`: about, news, selected publications
- `publications.html`, `projects.html`, `cv.html`: subpages
- `assets/css/main.css`: styles (change `--theme-color` to change the accent color)
- `images/profile.jpg`: profile photo (hidden if the file is missing)
